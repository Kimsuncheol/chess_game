# Still Chess — Unity 3D Board Project (`unity/ChessBoard`)

Android-compatible 3D chessboard scene and presentation-only `BoardRenderer` for the Still Chess Flutter application.

See [docs/unity_3d_scene.md](../../docs/unity_3d_scene.md) for full architecture, coordinate mapping (`a1`–`h8`),FEN snapshot reconstruction details, and step-by-step instructions to open, test, and run the project in Unity.

## Quick Start

1. Open **Unity Hub**, click **Add > Add project from disk**, and choose this folder (`unity/ChessBoard`).
2. Open `Assets/Scenes/ChessBoard.unity`.
3. Press **Play** (or choose **Tools > Still Chess > Rebuild 3D Chess Scene** in the menu bar) to generate the 8×8 chessboard and 32 standard starting pieces.
4. Run EditMode unit tests via **Window > General > Test Runner > EditMode > Run All**.
